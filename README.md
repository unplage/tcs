# 🐍 贪吃蛇·进化论

**触屏优化 | 音效反馈 | 成就系统 | 多模式**

在线体验：https://unplage.github.io/tcs/

## 特色

| | |
|---|---|
| **三种模式** | 经典（4 档难度）/ 限时狂潮（60s 倒计时）/ 生存极速（速度递增） |
| **全屏操控** | 110px 摇杆 + 画布滑动 + 键盘方向键，移动端全方位适配 |
| **音效反馈** | 15 种 Base64 合成音效（吃/连击/特殊/死亡/成就），支持静音切换 |
| **触觉反馈** | 节奏振动（`navigator.vibrate`），吃食/连击/死亡各不同，可关闭 |
| **平滑插值** | 蛇在格子间线性动画，告别跳帧 |
| **粒子特效** | 食物粒子喷射、死亡爆炸、连击辉光、屏幕震屏 |
| **5 种特殊食物** | 黄金（高倍分）/ 加速 / 减速 / 毒果 / 分身，动态概率 |
| **连击系统** | 2s 窗口连击，倍率递增，屏幕中央 🔥 弹出 |
| **12 项成就** | 初尝/百分/连击大师/传奇等，解锁弹出通知 |
| **游戏统计** | 总游戏数/最高分/最长长度/食物数等跨局持久化 |
| **PWA** | 离线可玩，Service Worker 缓存，GitHub Pages 部署 |

## 开发

```bash
npm install      # 安装依赖
npm run dev      # 开发服务器（HMR）
npm run build    # 构建到 dist/
npm run gen-audio # 重新生成 Base64 音效
```

基于 Vite + ES Modules 重构，单文件 (`index.html`) 作为 Vite 入口，所有逻辑拆分为 `src/` 下模块。
